# 🦇 Bat-Site

Um projeto web inspirado no universo do Batman, desenvolvido com HTML, CSS e JavaScript.
O objetivo é criar uma página interativa apresentando informações sobre o filme, elenco e conteúdo visual estilizado.

---

## 📌 Sobre o Projeto

O **Bat-Site** é uma aplicação front-end que simula um site temático do Batman, com navegação entre seções e layout moderno.

Ele foi desenvolvido com foco em:

* Prática de estruturação HTML
* Estilização com CSS
* Interatividade com JavaScript
* Organização de arquivos em um projeto real

---

## 🚀 Funcionalidades

* 📱 Menu responsivo (com botão de toggle)
* 🎨 Layout estilizado com tema escuro
* 🧭 Navegação por seções:

  * Home
  * Sobre
  * Trending
* 🖼️ Exibição de imagens do elenco
* ⚡ Interatividade com JavaScript

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## ▶️ Como Executar o Projeto

1. Clone o repositório:

```bash
git clone https://github.com/Williansilva2207/Bat-Site.git
```

2. Acesse a pasta do projeto:

```bash
cd Bat-Site/Bat\ Web
```

3. Abra o arquivo no navegador:

```bash
main.html
```

Ou simplesmente:

* Clique duas vezes no arquivo `main.html`
